When writing copy for the user (decks, pitches, messages), **avoid passive / apologetic / hedging phrasing**. Example the user flagged: *"Esto NO es un regaño…"* — denying it makes it read MORE apologetic.

**Why:** The user found such lines "muy pasivo y apologético" and prefers confidence.

**How to apply:**
- Be direct and confident. When you need to soften, use **light, healthy humor** (couple/casual humor for personal topics) instead of disclaimers.
- **Fact-check factual claims before presenting them.** The user actively fact-checks persuasive material (he caught a false "the sun barely heats us" claim, verified Guadalajara night temps, etc.). Don't ship claims that won't survive scrutiny — a refuted "star fact" sinks the whole pitch.
- For a persuasive deck, frame as a shared dream / win, not a sacrifice or a scolding.
